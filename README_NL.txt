# Verjaardagspagina – Permanente link handleiding (NL)

Deze map bevat de finale pagina met muziek (song.wav), hartjes-animatie en jouw tekst.

## Permanente link via Netlify (gratis)
1) Ga naar https://app.netlify.com/drop
2) Sleep de hele map **verjaardag_roshano_PERMA** in het venster.
3) Je krijgt direct een **.netlify.app** link.
4) (Optioneel) Maak gratis een account en wijzig de sitenaam naar iets blijvends zoals `roshnie-roshano-birthday`. De link wordt dan: `https://roshnie-roshano-birthday.netlify.app`.

Zie de Netlify-documentatie voor domeinen en naam wijzigen.
